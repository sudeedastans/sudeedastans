## 🚀 Selected Projects

### 📍 GPS Data Processing & Testing System
**C++ | Boost UTF | Git | Jenkins | CMake**

Developed a C++ system for parsing and analysing GPS coordinate data using **Test-Driven Development**.

I designed automated unit tests using the Boost Unit Test Framework, refactored existing code to improve maintainability, and used Git workflows including branching, merging and cherry-picking. I also worked with **Jenkins CI pipelines** for automated builds and testing.

---

### ☁️ Cloud Load Balancer System
**Java | Docker | JavaFX | MySQL | SQLite**

Built a distributed load-balancing system designed to distribute network requests between multiple storage servers.

The project included **Round Robin and FCFS scheduling algorithms**, Docker-based services, concurrency control, file locking, persistent database storage, and a JavaFX user interface for uploading and downloading files.

---

### 🎟️ Event Booking REST API
**C# | ASP.NET Core | SQLite | Entity Framework Core**

Developed a database-driven RESTful API for managing events, bookings, organisers and users.

Implemented CRUD operations across multiple endpoints together with **role-based authentication and authorisation** for Admin, User and Guest roles and integrated the API with a front-end application.

---

### 🌐 Event Web Application
**JavaScript | HTML | CSS | REST API**

Built a responsive front-end application for browsing and advertising events.

Implemented dynamic content rendering, REST API integration, responsive layouts and client-side form validation using JavaScript.

---

### 📦 Warehouse Inventory Management System
**C++ | OOP | File Handling**

Developed a console-based inventory management system with separate functionality for managers and employees.

The system supports inventory tracking, unique item IDs, stock quantities, warehouse locations, order creation and completion tracking while using file I/O to preserve data between executions.
